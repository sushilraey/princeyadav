## 🌟 About This Project

This personal website is designed to reflect Prince Yadav's personality, interests, and background as a Computer Engineering student from Bhaktapur, Nepal. Unlike traditional developer portfolios, this site focuses on creating a personal connection and sharing life experiences.

### Key Features:
- **Personal Introduction**: Get to know Prince beyond academics
- **Interests & Hobbies**: Discover passions in photography, hiking, reading, and music
- **Visual Gallery**: Experience Nepal's beauty through curated visuals
- **Responsive Design**: Seamless experience across all devices
- **Modern Aesthetics**: Warm color palette and elegant typography
- **Interactive Elements**: Smooth animations and engaging user interactions

## 🎨 Design Philosophy

The website embraces a warm, inviting aesthetic with:
- **Color Palette**: Muted blue-grays (#4A6572) paired with warm coral accents (#FF8A5B)
- **Typography**: Elegant Playfair Display for headings with clean Poppins for body text
- **Layout**: Clean, spacious design with thoughtful white space
- **Visual Elements**: Floating animations and smooth transitions
